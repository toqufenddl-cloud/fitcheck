# 프로젝트: 금융상품·소비자 특성 데이터 분석 (부트캠프 1차 프로젝트)

## 목표
- 고객 세분화와 상품 추천 분석으로 EDA → 기초 모델링 → 인사이트 리포트 완성
- 나는 데이터 분석을 배우는 중이다. 결과물보다 내가 이해하는 것이 우선이다.

## 작업 규칙
- 큰 작업은 먼저 계획을 보여주고, 내가 승인한 뒤 실행한다.
- 코드는 노트북 셀 단위로 나누고, 셀마다 한국어 주석을 단다.
- 결과 해석은 대신 쓰지 말고, 내가 쓴 해석을 검토해 준다.
- 컬럼 의미나 수치가 불확실하면 추측하지 말고 불확실하다고 말한다.

## 데이터 주의사항
- 출처: AI Hub 「금융상품·서비스 및 소비자 특성 데이터」 (한국지능정보사회진흥원)
- data 폴더의 원본은 git에 올리지 않는다. 배포물에는 집계 결과만 넣는다.
- 파일 전체를 읽지 말고 필요한 부분만 샘플로 확인한다.
