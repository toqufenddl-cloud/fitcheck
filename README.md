# FitCheck

LLM 학습용 금융 상담·추천 데이터의 품질 진단 도구.

## 문제

금융회사가 AI 상담 보조를 도입하려면 학습 데이터를 믿을 수 있어야 한다. 이 프로젝트는 투자상품 추천 시나리오(CoT) 데이터를
금융소비자보호 규정에 근거한 기준으로 진단하고, 기준을 충족한 데이터셋과 결함 유형별 분포, 보강이 필요한 영역을 제시한다.
평가 기준은 결과의 그럴듯함이 아니라 **과정의 정확성, 논리적 타당성, 근거**다.

진단 기준은 [`docs/판정기준서.md`](docs/판정기준서.md)에 있고, 판단 하나하나의 날짜와 이유는 [`docs/decisions.md`](docs/decisions.md)에 남겼다.

| 기준 | 내용 | 근거 |
|---|---|---|
| ① 필수정보 충족 | 질문·cot1에서 필수확인정보 6개(거래목적, 재산상황, 투자 경험, 상품이해도, 위험에 대한 태도, 연령)를 확인했는지 | 금소법 제17조②2호 |
| ② 성향 판단 근거 | 필수정보가 부족한데 투자성향을 확정했는지 | 금소법 제17조②·③ |
| ③ 적합성 일관성 | 추천 상품 위험등급이 허용 범위 안에 있는지 | 투자권유준칙 |
| ④ 위험 우선 설명 | answer에 손실 가능성과 위험등급이 있는지 | 금소법 제19조① |

## 접근

- **A. 규칙 검사**: 판정 규칙을 `src/rules/rules.csv`(시행일 포함)와 DataFrame 함수(`src/judge.py`, `src/criteria12.py` 등)로 만든다. 애매한 경우의 처리는 함수마다 주석으로 적는다. 규칙으로 정할 수 없는 경우는 새 규칙을 만들지 않고 "사람 확인"으로 둔다.
- **B. 근거 조항 검색**: 결함마다 근거 조항(법·감독규정·투자권유준칙)을 검색해 붙인다 (`src/rag/`).
- **G. 최신 공시 대조**: 추천 빈도 상위 30개 상품의 최신 공시 위험등급을 데이터 등록 등급과 대조하고, 최신 등급으로 범위를 다시 판정한다 (`src/latest_grade.py`). 조회에는 상품명만 쓴다.
- **C. 로컬 LLM 판정**: 규칙이 못 정하는 사례를 로컬 LLM으로 판정하려 했으나, 검증에서 결함 검출률이 기준에 못 미쳐(D61) **B안으로 축소**했다. LLM 결과는 보조 보고로만 쓴다. 원문은 외부 API로 보내지 않는다.

## 핵심 결과

`outputs/report_numbers.md`(2026-11-23 기준)에서 옮겼다. 대상은 증권 CoT 7,201건(Training 6,400 / Validation 801)이다.

| 지표 | 전체 | 비율 |
|---|---|---|
| ① 법정 3항목 중 미확인 있음 | 1,442 CoT | 20.0% |
| ② 근거 부족인데 성향 확정 (②-a) | 516 CoT | 7.2% |
| ② 성향 미확정인데 추천 (②-b) | 191 CoT | 2.7% |
| ③ 공개 기준 밖 추천 | 821 추천 (355 CoT) | 증권 추천 16,834건 중 4.9% |
| ③ 범위 밖 → 제외 | 373 CoT | 5.2% |
| ④ 위험등급 일부 기재 / 기재 없음 | 1,614 / 4,105 CoT | 22.4% / 57.0% |
| 성향 밖 등급 직접 추천, 상담사 이관 없음 | 126 CoT | 1.7% |
| G 최신 기준 부적합 (상위 30개 상품 추천) | 16 추천 | 등급이 바뀐 상품 5개 |
| 정제 데이터셋 (엄격판·교정판) | 각 6,828 CoT | 교정판에 ④ 등급 문장 10,900건 추가 |
| D61 로컬 LLM 검증 | 결함 아님 일치 14/14, 결함 검출 3/16 | → B안 |

사람 확인으로 남긴 사례: 이관 문장 31 CoT, 범위 표기 손상 1 CoT, 최신 등급이 바뀐 상품 5개, 조회 명칭이 다른 상품 1개, 원천 확인이 필요한데 공식 문서로 확인하지 못한 상품 318개.

## 폴더 구조

```
src/            판정 함수 (DataFrame을 받아 판정 결과를 돌려준다)
  rules/        판정 규칙 표 (rules.csv, 허용 범위 d43_range.csv, 이관 표현)
  rag/          근거 조항 검색·로컬 LLM 진단 (선택)
notebooks/      분석 노트북 (번호순 실행)
outputs/        집계 결과 (scorecard.csv, report_numbers.md, judgments.csv 등). 원문 없음
docs/           판정기준서, 결정 기록, 근거 자료 목록
submission/     분석 코드 모음 (src + 노트북 코드 셀)
data/           원본 데이터 위치 (git 제외)
```

## 실행 순서

| 순서 | 노트북 | 내용 |
|---|---|---|
| 1 | 01, 02, 02b | 소비자·CoT 데이터 구조, 일관성 점검 |
| 2 | 06 | CoT와 고객 DB 대표성 비교 |
| 3 | 03, 04 | 판정 함수 실행, 판정 규칙 검증 |
| 4 | 03b | 기준 ①② 판정 |
| 5 | 05, 05b | ④ 미기재 원인, G 최신 공시 대조 (조회 결과 캐시를 읽는다) |
| 6 | 07, 07b | 근거 검색, 로컬 LLM 검증 (선택, Ollama 필요) |
| 7 | 05c | 품질 점수표, 민감도, 정답지 오염 비교 |
| 8 | 08 | 엄격판·교정판 데이터셋 (`outputs/corrected/`, git 제외) |
| 9 | 07_결함요인모델 | 결함 요인 모델 (요인 분석용, 판정 아님, D66). 결과 `outputs/model/` |

노트북 번호는 결정 기록에서 참조하고 있어 실행 순서와 다르다(D29).

## 환경

- Python 3.12, `pip install -r requirements.txt`
- 선택: G 조회 다시 하기 `httpx`. 근거 검색·로컬 LLM `langchain-ollama`, `langchain-community`, `faiss-cpu`와 [Ollama](https://ollama.com)(모델 `exaone3.5:7.8b`, 임베딩 `bge-m3`). 주소는 환경변수 `OLLAMA_HOST_URL`(기본 `http://127.0.0.1:11434`).

## 데이터 (포함하지 않음)

이 저장소에는 원본 데이터와 원문 문장이 들어 있지 않다. 보고·문서에는 원문을 인용하지 않고 cot_id와 상품명만 쓴다.

1. AI Hub 「금융상품·서비스 및 소비자 특성 데이터」를 AI Hub 이용 조건에 따라 신청해 받는다.
2. 받은 zip을 압축을 풀지 않고 아래처럼 둔다. 코드가 zip을 바로 읽는다 (`src/load_cot.py`).

```
data/raw/Training/01.원천데이터/*.zip
data/raw/Training/02.라벨링데이터/*.zip
data/raw/Validation/01.원천데이터/*.zip
data/raw/Validation/02.라벨링데이터/*.zip
```

사람 검수표(`data/review/`)와 LLM 응답 캐시(`data/llm_cache/`)도 원문이 들어 있어 포함하지 않는다. 이 파일이 필요한 노트북 단계는 다시 만들어야 한다.

이 데이터는 AI 학습용으로 생성된 데이터다. 결과를 실제 고객 행동으로 해석하지 않는다.

## 출처

이 결과물은 한국지능정보사회진흥원의 사업 결과로 구축된 데이터를 활용했습니다.

- 데이터: AI Hub 「금융상품·서비스 및 소비자 특성 데이터」 (한국지능정보사회진흥원)
- 근거 문서 (원문 파일은 포함하지 않음, 목록은 [`docs/sources.md`](docs/sources.md)·`docs/regulations/regulations_index.csv`)
  - 금융소비자 보호에 관한 법률 (국가법령정보센터)
  - 금융투자협회 표준투자권유준칙
  - 한국투자증권 투자권유준칙
  - KB국민은행 투자성향별 적합 위험등급 표
  - 금융위원회 보도자료 (고난도 금융투자상품 판매 개선, 홍콩 H지수 ELS 제재)
  - 운용사 공시 (NH-Amundi자산운용 펀드 페이지, 교보악사자산운용 자산운용보고서)
- 최신 위험등급 조회: [FunETF](https://www.funetf.co.kr) (펀드 정보 사이트, 참고). [금융투자협회 전자공시](https://dis.kofia.or.kr/)의 펀드 기본정보에는 위험등급 항목이 없다 (D65).
