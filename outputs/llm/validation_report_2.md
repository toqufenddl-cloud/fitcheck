# LLM 2차 시도 결과 (D61, 2026-11-19)

판정 없이 사실만 적는다. 노트북: `notebooks/07b_LLM_2차.ipynb`, 사례별 결과: `outputs/llm/classify_results.csv`.

## 설정 (1차와 다른 점)

- LLM 역할: (a) 등급 언급 문장 분류(희망/고려 중/경험/회피/비교 표현/일반 표현), (b) answer의 이관 표현 여부만. 범위·사유 코드·원천은 규칙 결과를 그대로 쓴다.
- 결함 = 규칙의 성향 밖 판단 + LLM 분류·이관 표현을 코드로 결합 (`src/rag/classify.combine`). 프롬프트에 규칙 판정 없음.
- 예시 5개: 검증 표본 밖 CoT(2621, 1514, 2228, 2417, 5291). 일반 표현 예시는 없음.
- 색인 613조각: 한국투자증권 준칙(항 단위) 198, 금소법 210, 표준투자권유준칙 190, 상품 15. 사례마다 자기 값으로 검색 질의를 만든다.
- 실행 중 바로잡은 것: 임베딩을 한 번에 모두 보내면 Ollama 러너가 멈춰 8개씩 나눔, 1,500자를 넘는 조각은 줄 경계에서 나눔, 검색(bge-m3)을 먼저 끝내고 모델을 내린 뒤 LLM 실행.

## 결과

- 90건(새 30 + 희망 40 + 이관 20) 모두 형식 정상, 재시도 0, 평균 1.5초.
- LLM 이관 표현 true: **79 / 90**. 규칙(03)과 D40(02b F3)에서는 이관 표현이 있는 CoT가 0건이다.
- LLM 분류: 고려 중 39, 회피 32, 경험 11, 비교 표현 5, 희망 3. 확신도는 90건 모두 '높음'.
- 결합 판정: 결함 7, 결함 아님 83.
