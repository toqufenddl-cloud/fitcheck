## 설정

- 모델: exaone3.5:7.8b(진단, temperature 0, num_ctx 4096, JSON 스키마 강제), bge-m3(임베딩). Ollama, 이 컴퓨터 안에서만 (D60).
- 근거 문서: 한국투자증권 투자권유준칙(89 조항), 상품 문서 2개. 금소법·시행령·금융투자협회 표준투자권유준칙·KB국민은행 표는 파일이 없어 색인에 없다.
- 검색: 기준일 2026-11-19, 회사 기준 한국투자증권, 상위 5개 조항을 근거로 넣음. 프롬프트에 검증 표본의 예시는 넣지 않음.

- **LLM은 112건 중 111건을 '결함'으로 판정했다** (나머지 1건은 근거 부족).
  - 사람 판정이 결함인 66건: LLM 결함 66건.
  - 사람 판정이 결함 아님인 46건: LLM 결함 아님 1건, 결함 45건.
  - 그래서 결함 표본(범위밖, 희망검수표2)의 높은 일치는 결함을 가려낸 결과가 아니다.
- 희망검수표1(회피 9, 오탐 11): LLM이 이관 분류를 '회피'로 적은 5건도 결함으로 판정했다.
- 원천 20: 20건 모두 결함·태그·원천 오류 (사람: 오류 4, 오탐 16).
- 범위 사유 코드: LLM 코드 4가 30건, 2가 2건 (사람: 2가 21건).
- 확신도별 결함 일치: 높음 44/83(53%), 중간 23/26(88%), 낮음 0/3.
- 사람 확인으로 갈 사례: 규칙만 13건 → 규칙 + LLM 35건 (규칙과 다름 30, 확신도 낮음 3, 인용 오류 1, 근거 부족 1).
- 검색
  - 범위 32건: 정답 조항(한국투자증권 제6조)이 상위 3개 안에 32/32.
  - 이관 60건: 정답 조항(제6조, ③항)이 상위 3개 안에 0/60. 60건 모두 같은 질의라 상위 3개가 같았다(제7조, 제28조, 제5조). 제6조 ③항은 ①항과 같은 조각(제6조-1) 안에 있다.
- 인용 조항이 검색 결과 안에 있는 비율 99.1% (인용 오류 1건).
- JSON 형식: 첫 시도 실패 0, 재시도 후 실패 0 / 112. 평균 2.8초, 최대 9.2초.
- 회사 기준 시연: KB국민은행 문서가 없고, 검색 후보 40개가 모두 한국투자증권 조항이라 회사 필터 뒤 결과가 비었다. 시행일이 적힌 문서가 없어 기준일 시연도 하지 못했다.

## 표본별 한계

- 범위밖 32: D57 규칙을 이 표본을 보고 만들었다 (규칙 일치율이 낙관적). LLM 쪽에는 해당하지 않는다.
- 희망검수표 1·2: 이관 키워드를 이 40건으로 정했다. 희망검수표1에는 결함 사례가 없다.
- 이관검수표 20: 경험 규칙을 이 20건을 보고 고쳤다. 성향 밖 15 + 성향 안 5로 뽑아 전체를 대표하지 않는다.
- 원천 20: H1 키워드 후보에서 뽑은 표본이다. 프롬프트에 규칙 판정을 '참고'로 넣었으므로, LLM이 규칙 판정을 따라갔을 가능성을 이 결과로는 구분할 수 없다.
